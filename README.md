## 🚀 Flagship Engineering Systems

### 1. DELUGE 3D — Coastal Flood Intelligence Platform
*Physics-Driven Flood Simulation for Climate-Resilient Planning*
- **Hydrodynamic Engine**: 2D Saint-Venant Shallow Water Equations with shock-capturing finite difference discretization.
- **Topographic Interaction**: Adaptive DEM mesh elevation slicing with dynamic Manning-Strickler bed friction coefficients ($n = 0.020 - 0.060$).
- **Scenario Modeling**: 100-Year pluvial cloudbursts (120mm/hr), Category 3 storm surges (+2.8m), and IPCC SSP5-8.5 permanent sea level rise projections (+1.2m).
- **Interactive Viewport**: WebGL depth contouring and vector runoff routing with gauge hydrograph inspection.

### 2. SATVision — Satellite Orbit & Overpass Intelligence
*Predicting Orbital Coverage Through Real-Time Spatial Computation*
- **Astrodynamics Engine**: SGP4/SDP4 analytical satellite orbit propagation from active NORAD Two-Line Elements (TLE).
- **Real-Time Telemetry**: Real-time Cartesian ECI $\to$ GMST geodetic coordinate transformations (Latitude, Longitude, Altitude, Orbital Velocity $\approx 7.49\text{ km/s}$).
- **Sensor Footprints**: Dynamic geometric ground-track swath projection for Copernicus Sentinel-2A ($290\text{ km}$ swath), USGS Landsat-9 ($185\text{ km}$ swath), and ISS.
- **Proximity Radar**: Automated distance calculation and overpass acquisition window countdown for ground station nodes (e.g. Chennai Base $13.0827^\circ\text{N}, 80.2707^\circ\text{E}$).

### 3. SWAT Weather Data Generator (Copyright: SW-17836/2026-CO)
*Automating Climate Data Preparation for Hydrological Research*
- **Scientific Pipeline**: Automated batch queries to NASA POWER agroclimatology and ECMWF ERA5-Land reanalysis grids over 40-year spans.
- **Thermodynamic QA**: Magnus-Tetens vapor pressure calculations, FAO-56 solar radiation conversions, and Pettitt homogeneity anomaly detection.
- **Fortran Alignment**: Rigorous fixed-width ASCII generation for SWAT/QSWAT/ArcSWAT station tables (`.pcp`, `.tmp`, `.slr`, `.hmd`, `.wnd`), reducing data preparation from weeks to minutes.

## 💻 Local Development & Build Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```

### 4. Start Production Server
```bash
npm run start
```
